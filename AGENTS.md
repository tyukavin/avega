# Универсальные инструкции для AI-ассистентов

`AGENTS.md` — единая каноническая точка входа для любой нейросети или AI-среды, работающей с проектом. Правила не зависят от Codex, OpenCode, DeepSeek, Claude, Gemini, Copilot или другого конкретного инструмента.

## Обязательная загрузка инструкций

Перед чтением, анализом или изменением исходного кода любой AI-ассистент обязан полностью прочитать этот файл и все документы:

- [`ai/instructions/markup.md`](ai/instructions/markup.md) — семантика HTML, БЭМ, формы, доступность, SVG и SEO;
- [`ai/instructions/styles.md`](ai/instructions/styles.md) — SCSS, CSS-переменные, адаптивность, темы и порядок свойств;
- [`ai/instructions/scripts.md`](ai/instructions/scripts.md) — ESM-модули, DOM-состояния, Swiper.js, безопасность и progressive enhancement;
- [`ai/instructions/assets.md`](ai/instructions/assets.md) — шрифты, изображения, SVG-спрайты и создание страниц;
- [`ai/instructions/quality.md`](ai/instructions/quality.md) — контракт компонентов, производительность, проверка и CI/CD.

Нельзя считать, что среда загрузила эти файлы автоматически. Если инструмент не поддерживает ссылки на дополнительные инструкции, прочитай их средствами файловой системы до начала работы. Не изменяй затронутую область проекта, пока соответствующие правила не прочитаны.

Этот файл и документы в `ai/instructions/` являются единственным источником проектных правил. Конфигурации отдельных AI-инструментов могут только подключать их и не должны содержать уникальные или дублирующие требования. При противоречии остановись, укажи конфликт и руководствуйся более конкретной явной инструкцией пользователя.

## О проекте

Gulp-сборка для многостраничной HTML/PHP-вёрстки. Исходники в `src/`, результат сборки в `build/`. Файлы в `build/` и `.cache/` генерируются автоматически — не создавай и не редактируй их вручную.

Команды:

- `npm start` — dev-сервер с BrowserSync (HTML)
- `npm run php` — dev-сервер для PHP (требуется `PHP_PROXY`)
- `npm run build` — чистая production-сборка
- `npm run check` — format + lint + build + html-validate
- `npm run deploy` — сборка и SFTP-загрузка

Не устанавливай новые npm-пакеты и не меняй раздел `devDependencies` без явного запроса. Исключение: Swiper.js (допустимая runtime-зависимость).

## Общие правила

Правила применяются ко всему исходному коду проекта. Перед изменением существующего компонента изучи его разметку, стили и поведение. Не меняй публичные классы, `data-*`-атрибуты и структуру шаблонов без необходимости.

Во всех исходных HTML, CSS, SCSS, JavaScript, JSON и конфигурационных файлах используй четыре пробела на уровень вложенности. Табуляция запрещена. Vendor-файлы и сгенерированный код не переформатируй.

Настройки форматтеров, линтеров и сборки должны обеспечивать требования инструкций. Если автоматический инструмент противоречит инструкции, не игнорируй расхождение: установи причину и согласуй конфигурацию в рамках задачи либо явно сообщи о конфликте.
